## Überblick

MinJ (Minimalistic Java) ist eine Skriptsprache, mit der ich verstehen wollte, wie ein Interpreter von innen funktioniert. Sie hat Klassen, Methoden, typisierte Variablen, Schleifen, Listen und `return` und läuft auf der JVM. Aus einer ANTLR4-Grammatik mit 246 Zeilen entstehen Lexer und Parser, ein `EvalVisitor` mit rund 730 Zeilen läuft den Parse Tree ab und führt ihn aus, und alles zusammen steckt in einem Fat-JAR, das überall läuft, wo es Java 21 gibt.

Ich wollte jede Schicht selbst implementieren, statt nur darüber zu lesen: Lexing, Parsing, Scoping, Typprüfung und Method Dispatch.

## Funktionsweise

Quellcode geht durch drei Stufen:

1. `MinJ.g4` definiert die Grammatik. Der Gradle-Build lässt ANTLR4 daraus `MinJLexer` und `MinJParser` erzeugen.
2. `EvalVisitor` erweitert ANTLRs `MinJBaseVisitor<Object>` und überschreibt eine Methode pro Grammatikregel. Jeder `visit*`-Aufruf läuft seinen Teil des Baums ab und führt ihn aus: Variablen anlegen, rechnen, Kontrollfluss, Method Dispatch und Objekte erzeugen.
3. `Main.java` liest eine `.mj`-Datei, schickt sie durch Lexer und Parser und ruft `visitor.visit(tree)` auf.

Grammatik und Ausführung sind getrennt. Die `.g4`-Datei legt fest, wie ein MinJ-Programm aussieht, und `EvalVisitor`, was es tut. Für ein neues Sprachkonstrukt ändert man deshalb genau diese beiden Dateien.

Zur Laufzeit liegt jede Variable in einer `Cell`. Die speichert den Wert, den deklarierten Typ, ob die Variable veränderlich ist und ob sie dynamisch typisiert ist. Eine `return`-Anweisung wirft ein `ReturnSignal`, eine Unterklasse von `RuntimeException`, und baut damit den Call Stack ab. So funktioniert ein Return auch mitten in verschachtelten Schleifen und Bedingungen. Ein neues Objekt kopiert die Feld-Cells seiner Klasse, damit jede Instanz ihren eigenen State hat.

## Die Sprache

`var` deklariert eine veränderliche, dynamisch typisierte Variable, `val` eine unveränderliche. Explizite Typen sind `int`, `float`, `double`, `boolean`, `char` und `String`. Bei typisierten Deklarationen wird jede Zuweisung geprüft: Wer einer `int`-Variable einen String zuweist, bekommt einen Fehler.

Für den Kontrollfluss gibt es `if`/`elseif`/`else`, `while`, `for i = 1 to n step s` und `foreach x in list`. Blöcke enden mit `end`. Boolesche Operatoren gibt es als Symbole oder Wörter (`&&` oder `and`, `||` oder `or`, `!` oder `not`).

Klassen haben Felder und Methoden, `new` erzeugt eine Instanz. Globale Funktionen werden mit `func` definiert, und ein `return` kann mehrere Werte zurückgeben. Kommentare beginnen mit `//` oder `#` oder stehen zwischen `/*` und `*/`.

## Beispiele

### FizzBuzz

```minj
val limit = 100
for i = 1 to limit do:
  if i % 15 == 0 then:
    print "FizzBuzz"
  elseif i % 3 == 0 then:
    print "Fizz"
  elseif i % 5 == 0 then:
    print "Buzz"
  else:
    print i
  end
end
```

### Klassen und Methoden

```minj
class Counter:
  var count = 0
  method inc():
    count = count + 1
  end
  method get():
    return count
  end
end

var c = new Counter()
c.inc()
c.inc()
print c.get()   // 2
```

### Rekursive Fakultät

```minj
func factorial(n):
  if n <= 1 then:
    return 1
  end
  return n * factorial(n - 1)
end

print factorial(5)   // 120
```

## Build und Releases

Der Gradle-Build erzeugt Lexer und Parser mit dem ANTLR-Plugin jedes Mal neu aus `MinJ.g4`. ShadowJar packt alles, auch die ANTLR-Runtime, in ein Fat-JAR. Ein Skript startet man mit `java -jar minjc-<version>.jar file.mj`.

Ein GitHub-Actions-Workflow läuft bei jedem Push auf einen Branch namens `release-v*`. Er baut das Fat-JAR mit JDK 21, packt es mit den Beispielen und der README in ein Zip, legt ein Release mit der Version aus dem Branch-Namen an und hängt das Zip als Release-Asset an. Die Doku liegt auf GitHub Pages.

## Die Sprache erweitern

Ein neues Konstrukt braucht vier Änderungen. So ist die `while`-Schleife dazugekommen:

1. Eine Grammatikregel in `MinJ.g4`:
```antlr
whileStmt : WHILE expr DO COLON block END ;
```

2. Sie in der Regel `statement` eintragen:
```antlr
statement : varDecl | assign | printStmt | ifStmt | whileStmt ;
```

3. Lexer-Token:
```antlr
WHILE : 'while' ;
DO    : 'do' ;
END   : 'end' ;
```

4. Ein Visitor-Override in `EvalVisitor.java`:
```java
@Override
public Object visitWhileStmt(MinJParser.WhileStmtContext ctx) {
    while ((Boolean) visit(ctx.expr())) {
        visitBlock(ctx.block());
    }
    return null;
}
```

Danach mit `./gradlew clean shadowJar` neu bauen.
